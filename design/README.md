The development prompt overrides inconsistencies in the images:
- Selection belongs to each user, not the shared kitchen; inventory is shared.
- Confirmation examples are alternative states, not permanently stacked modals.
- Shared-kitchen membership must be enforced on the server.
- Food category and storage location are separate fields; Frozen is a location-based shortcut.
- Add and edit use the same form; no separate details, photo-review or saved-success pages.
- Calculation explanations should be short, with details in an information disclosure.
- Generated recipe steps are demonstration copy requiring team review.

Do not use superseded photorealistic fridge designs or the old four-page entry board.
